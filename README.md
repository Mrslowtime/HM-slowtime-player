# 慢时光音乐 · HarmonyOS 原生版

一款基于 HarmonyOS ArkTS 开发的原生音乐播放器。搜索、歌单、排行榜、逐字歌词、本地音乐、自建歌单、主题与多语言，全部为原生实现。

## 功能

- 在线搜索、歌手/专辑、排行榜、在线歌单（酷狗 / 酷我 / QQ 音乐 / 网易云 / 咪咕等平台）
- 逐字歌词（KRC / QRC / LRC）解析与高亮、封面缓存
- 播放队列、音质切换、断点续播、定时停止、倍速
- 锁屏 / 通知播控卡片，桌面歌词
- 本地音乐导入、自建歌单、收藏、最近播放
- 多主题、多语言（简中 / 繁中 / English）、平板适配

## 构建

环境：DevEco Studio 5.0+，HarmonyOS SDK 6.0.0(20)（API 20）。

```bash
# 1. 用 DevEco Studio 打开项目根目录，等待依赖同步（ohpm install）
# 2. 配置自己的调试签名证书（见下）
# 3. 构建 HAP：Build > Build Module(s) > assembleHap
#    或命令行：hvigorw --mode module -p product=default assembleHap
```

产物位置：`entry/build/default/outputs/default/entry-default-signed.hap`

### 签名配置

`build-profile.json5` 中的签名证书路径为占位内容，请替换为你自己的调试/发布证书：

```json5
"signingConfigs": [
  {
    "name": "default",
    "type": "HarmonyOS",
   "material": {
  "certpath": "...",        // 你的 .cer 证书路径（本地配置，勿入库）
  "keyAlias": "...",
  "keyPassword": "...",
  "profile": "...",         // 你的 .p7b 调试 profile
  "signAlg": "SHA256withECDSA",
  "storeFile": "...",       // 你的 .p12 密钥库路径
  "storePassword": "..."
}

  }
]
```

签名证书（`.p12` / `.cer` / `.p7b`）与 `local.properties` 已通过 `.gitignore` 排除，不会进入仓库。

## 音源配置

**本软件不内置任何音源。** 首次启动时「自定义源」面板为空，这是预期行为。使用前请二选一：

1. **导入 JS 音源脚本**：进入「设置 → 自定义源管理 → 在线导入」（填脚本 URL）或「本地导入」（选本地 .js/.txt 文件）。脚本需符合通用 JS 音源脚本格式（文件开头有 `/* @name ... */` 块注释）。
2. **填写音源服务地址**：进入「设置 → 音源服务」，填入兼容 HTTP 音源服务的地址与密钥。

导入后回到设置页勾选启用该音源，即可播放在线歌曲。脚本与音源服务由用户自行获取并负责，本项目不提供、不内置、不推荐任何具体音源。
